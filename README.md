# Task 3 – Data Visualization | CodeAlpha

## Project
Books Data Visualization Dashboard using Python, Pandas, Matplotlib, Seaborn and Streamlit.

## Visualizations
- Book price distribution
- Rating distribution
- Availability composition
- Highest-priced books

## Run
```bash
pip install -r requirements.txt
python src/visualization.py
streamlit run app.py
```

The included sample dataset is only a demonstration. For final internship analysis, replace it with the full `books_dataset.csv` generated by Task 1.
