# TASK 3 REPORT – DATA VISUALIZATION

## Objective
Transform the book dataset collected in Task 1 into clear charts, summary statistics and an interactive dashboard.

## Tools
Python, Pandas, Matplotlib, Seaborn and Streamlit.

## Visualizations
1. Price distribution histogram
2. Rating distribution bar chart
3. Availability pie chart
4. Highest-priced books horizontal bar chart

## Dashboard
The Streamlit dashboard displays record count, average/minimum/maximum price, price comparison, rating distribution and a dataset preview.

## Important
The included dataset is a small demonstration sample. It must not be treated as representative of the complete catalogue. Use the full Task 1 output before making final business/data claims.

## Conclusion
The project demonstrates the workflow of cleaning data, creating meaningful visualizations and presenting findings through an interactive dashboard.
